# Public fitted allocation pair

Alexander Serov, Independent Researcher. The original frozen reader-v5 ran once and reported eligibility; an independent data-association review retained the original inspection and output identities recorded in association.json. The exact paired-models.json is copied without reserialization or fitting. The pair uses all 16 original complete public-development windows from four games: 13 zero labels and 3 positive labels; positives occur in only one game/episode. This is a small development fit, not a held-out evaluation.

A1 and P preserve the fixed feature bases, preprocessing, L2=1, 2000 iterations and learning rate 0.05. Their design ranks are both 14; Brier residual features are near the span of the common moments, so any comparison concerns a fixed regularized representation rather than independent residual information. No efficacy improvement or official score follows from fitting.

This release contains no raw training rows, notebook payload, account data, local private paths or LLM weights. Hashes of omitted original evidence preserve identity without redistributing it. The original trusted runtime bundle is unchanged and remains separate; this compact association must not be relabelled as the full runtime eligibility bundle.
