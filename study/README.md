# Frozen study documents

These four documents are exact, unchanged copies of the adopted scientific
protocol, calibration methods, audit budget and public-game split. This
prospective public release retains those choices before calibration, the main
ten-game audit, full published-policy (Bpub) reproduction and corresponding
official P outcomes. The public Git commit records publication timing; the dates
inside the documents are their adoption dates, not a fabricated publication
receipt.

The original development fit and available DEV observations were already known.
These documents do not retroactively preregister that development work or turn
its incomplete results into completed comparisons. The fixed games are from an
exposed public corpus, not a clean hidden test set; request seeds do not establish
independent game worlds or independent statistical replicates.

This directory creates no job, result, launch permission, reviewer approval or
official competition score. Budget ceilings are neither consumption measurements
nor quota reservations. Referenced workspace artifact paths and hashes are
identifiers for the retained research record; not every referenced artifact is
supplied in this public repository. No private notebook outputs, credentials,
account/browser metadata or raw training rows are copied here.

`manifest.json` records SHA256 for only the four unchanged document copies,
using their original `research/` and `configs/` relative paths. This README and
the manifest are curation metadata rather than changes to the frozen documents.

The protocol and calibration prose is CC BY 4.0 under the paper's declared terms. Original study configuration files are MIT-0; inherited code/model terms remain separate.
