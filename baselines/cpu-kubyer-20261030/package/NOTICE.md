Exact upstream LICENSE and README are included under upstream/. The retained
source manifest records every original URL, SHA256 and byte count. Our separate
wrapper does not modify or relicense these upstream files.

This is the disclosed goals-on, SUCCESS_OFF=1, absent-toy-prior variant, with
the original MDL defaults and fresh agent seed606. It is not the full upstream
learned-success method, the Franzen/Duck baseline or a reproduced official score.
Only public state/levels/advertised action IDs/frame arrays cross the proxy.
The language_model_calls=0 counter excludes the native MDL fitting and
prediction work performed by this CPU solver. Native model-call counts are
not instrumented; CPU, wall and peak RSS account for the actual process work.

The official ARC Prize starter interface is referenced, not copied. Its pinned
source/provenance is in interface-provenance.json. Repository license metadata
did not advertise a license; no starter builder implementation is bundled.
The exact public flag truthiness and gateway-owned parquet contract are API
semantics. No model weights, toy priors, training files, environment sources,
answers, cached games, private outputs or account credentials are in this package.

Ordinary private Save verifies source and records installed distribution and
supplied competition-wheel metadata (filename, bytes, SHA256 and requirements), then
creates an explicitly labelled validator placeholder. It imports no game SDK
or solver and performs no gameplay. A true rerun alone installs the two pinned
official game SDK versions from the competition wheelhouse, without dependencies
or network, validates the complete active installed requirement closure, and
uses one actual COMPETITION scorecard for the supplied roster. Other required
packages must already be available. No macOS binary overlay is exported.

Per-game120s is a soft Python signal bound; native calls can defer delivery.
The notebook parent enforces whole1800s from first code, including setup, and
kills/reaps the worker process group at that limit (bounded additional1s reap).
All factory RESETs, later RESETs and replay/policy actions count toward512/game.
Per-game failures/unresolved dispatches and unplayed roster rows are retained;
there is no fallback action, repair, retry, extra make or synthetic true score.
The gateway owns the final true submission.parquet after the same scorecard
lifecycle. The pinned starter and SDK client do not specify a filesystem
readiness barrier: immediate post-close file availability remains unobserved.
The entry retains its post-close nonempty-file check without guessing a wait
or a parquet schema. Source assembly proves neither compatibility nor progress.

The earlier observed CPU image metadata is a preparation prior only: CPython
3.12.13, NumPy2.4.6, requests2.32.4; arc-agi absent before its offline install.
SciPy/pandas/PyArrow/Pillow readiness is not established by that old record.
False-Save metadata must inform root's later decision before any actual Submit.
No remote operation or launch allowance is created by building this package.
