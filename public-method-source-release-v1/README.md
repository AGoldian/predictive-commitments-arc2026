the pinned competition, dataset and model attachments recorded in
`notebook/kernel-metadata.json` and `notebook/release-notices/DEPENDENCY-REFERENCES.json`.

separately licensed dependencies; this local archive grants no launch permission

worker, game SDK, model or scoring gateway. The placeholder's numeric sentinel is
not a measured score. Only the actual competition-rerun branch runs the full P
method on the SDK-supplied roster and retains the strict gateway-produced output.

output. The selected capacity is min(2,N); this is not the original published
