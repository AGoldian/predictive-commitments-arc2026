# Exact fitted allocation parameters

MIT-0 original research artifact. paired-models.json contains the byte-exact frozen A1/P coefficients, intercepts, feature order, means, scales, missingness basis and fitting metadata. model-config.json describes the existing loader/inference contract and exact source hashes; association.json records the original reviewed evidence hashes using portable relative references.

The pair file is directly compatible with the existing low-level load_model_pair contract when its canonical absolute path and exact SHA256 are supplied in the matching source installation. This folder is not a substitute for the separate scientific model-binding bridge bundle or a runnable competition entry. The forthcoming repaired full-entry assembly must supply its reviewed deployment/provenance binding. No model was refitted and no experimental source or original custody bundle was edited.
